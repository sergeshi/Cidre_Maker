# CIDREMAKER Desktop

Нативное настольное приложение на Python + PySide6 для журнала производства сидра. Читает и записывает существующую схему `cider_data.json` v2.3, сохраняя незнакомые поля и вложенные данные.

## Запуск в Windows

1. Установить Python 3.11 или новее.
2. Открыть терминал в `python_app`.
3. Выполнить:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

При первом запуске приложение автоматически создаёт локальную JSON-базу в `%USERPROFILE%\.cidremaker\cider_data.json` и загружает встроенные партии из `python_app/cider_data.json`. При следующих запусках данные подхватываются автоматически. Изменения сохраняются автоматически примерно через секунду после редактирования. Кнопки открытия внешнего JSON нет; импорт и экспорт резервной копии доступны в меню и внизу окна.

## Реализовано

- Обновлённая тёмная тема с графитовой основой, приглушёнными зелёно-мятными акцентами, более выразительной типографикой и скруглёнными панелями.
- Дашборд показывает объём незавершённых партий, общий объём и объём партий за выбранный год; год выбирается в верхней панели.
- Создание, дублирование и удаление партий; редактирование основных полей пяти технологических этапов и расширенный JSON-редактор.
- Кнопка **«Завершить партию»** фиксирует дату завершения, меняет статус на «Готово», сохраняет запись в истории этапов и добавляет событие завершения в производственный календарь.
- Встроенная JSON-база в профиле пользователя: автоматическая загрузка, автосохранение, атомарная запись и объединение начальных данных по ID без перезаписи локально изменённых партий.
- **Календарь производства** с подсветкой событий и списком событий выбранного дня: отжим, начало брожения, снятие с осадка, розлив, финиш/дегоржаж, дегустация, упаковка, замеры, подкормки, батонаж и операции Solera.
- **Timeline** в виде временной шкалы технологических этапов с отметкой текущей даты и переходом к партии по клику.
- **График брожения** по датам и значениям Brix/плотности из журнала замеров.
- **Калькулятор Pet-Nat**: оценка скорректированного Brix/SG, ABV, остаточного сахара, ориентировочного давления, целевого сахара и предупреждений по запасу давления бутылки.
- **Инструменты Solera**: журнал отбора/пополнения, пересчёт объёма и ориентировочного среднего возраста, предупреждение при отборе сверх доступного объёма.
- **Фото этикеток**: загрузка, просмотр и удаление изображения в папке `pix/` рядом с выбранным JSON-файлом.
- Импорт/экспорт JSON, резервные копии и атомарное сохранение.

## Важные замечания

- При первом запуске в базу включены 15 уникальных партий из `cider_data.json`; файл `cider_data1.json` в репозитории полностью совпадает с ним, поэтому повторные копии не добавляются. Перед первой работой с реальным журналом всё равно сделайте резервную копию базы и папки `pix/`.
- Расчёт Pet-Nat — технологическая оценка, а не гарантия давления. Перед розливом проверяйте фактический остаточный сахар, температуру, метод измерения и рейтинг бутылок. Нельзя использовать расчёт как замену безопасной технологической процедуре.
- Для партий Solera сохраняется базовый объём/возраст для повторного пересчёта операций без повторного применения изменений при каждом обновлении интерфейса.
- Тесты запускаются командой `python -m unittest discover -s tests -v` из каталога `python_app`.
